# HomeCraft Shop

HomeCraft is a furniture shopping website built with HTML, CSS, and JavaScript.

## Features
- Search products
- Filter products by category
- Sort products by price
- Add and remove cart items
- Apply discount coupons

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` using Live Server.

## State → Render Explanation
The state object stores the current search query, selected category, sorting option, cart items, and discount. When the state changes, `render()` updates the product grid, summary, category buttons, and cart UI to show the latest data.
